清洗规则与理由：

| 规则 | 理由 |
|---|---|
| `bbox_out_of_bounds` | 元素框超出截图范围。剔除而不裁剪——剔除量异常时正好暴露格式解析错误 |
| `bbox_too_small` | 元素框面积小于 100px²，既难点中也多半是标注噪声 |
| `bbox_degenerate` | 元素框宽或高为 0，通常是 xywh / xyxy 混淆的产物 |
| `point_out_of_bounds` | 落点超出截图范围 |
| `no_text_no_type` | 既无指令文本也无类型信息，无法构成监督信号 |
