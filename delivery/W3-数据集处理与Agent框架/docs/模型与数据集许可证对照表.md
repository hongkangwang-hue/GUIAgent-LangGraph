## 为什么不能用「全部开源、禁止商用」这类笼统口径

各来源的许可并不一致，而且**不一致的方向常常和直觉相反**：

- ScreenAgent 数据集是 Apache-2.0，**本身不禁止商用**；但同一个项目的
  模型权重走 CogVLM 协议，代码走 MIT——一个项目三种许可。
- **Qwen2.5-VL-3B 是 `qwen-research`（仅限研究），而更大的 7B 反倒是
  Apache-2.0。** 本项目按 8GB 显存选的正是 3B，也就是选到了限制更严的
  那一个。这条如果不写清，「我们的方案可私有部署商用」就是错的。
- Llama 3.2 的权重是 **gated（需申请且人工审批）**，不是下载即用。

### 本项目自身的约束严于上表任何一行

官方大纲「合规与落地说明」第 3 条：**「所有数据集均来自公开开源渠道，
严禁用于商业用途。」**

也就是说，即便上表里多数来源的许可证**允许**商用，**本项目自己不商用**。
上表存在的意义不是给商用开绿灯，而是 M2 任务 1 明确要求的那件事——
不用「全部开源、禁止商用」这类笼统口径，逐项记清各来源的真实条款，
以便 M5 报告在描述「技术方案可否私有部署 / 可否商用」时有据可依，
而不是凭印象断言。

### 一条数据集之外的合规约束

许可证管的是数据本身。本项目还有 M0 全局约束 1 的**数据边界**：
虚拟机内只安装测试软件、只用为本项目新建的测试账号、只操作预置测试文件；
不登录任何真实个人账号。这与许可证无关，但同属「能不能拿出去讲」的范畴。

## API 服务（在线调用路线）

API 调用不涉及权重许可，受约束的是**服务条款**与**数据出境**。

| 服务 | 模型 | 约束 |
|---|---|---|
| 阿里云百炼 | `qwen3-vl-8b-instruct` | 服务条款；**截图会上传到服务方** |
| 智谱开放平台 | `glm-4.6v-flash` | 同上 |
| NVIDIA NIM | `meta/llama-3.2-11b-vision-instruct` | 同上，且底层权重仍受 Llama 3.2 协议约束 |

**所有在线路线都有同一条约束**：规划层走云端 API 意味着客机截图会离开
本机。这正是 M0 要求客机内不放任何真实个人数据的原因——虚拟机解决的是
**执行隔离**，不解决**数据隐私**。

### 「所有操作均在本地计算机上进行」到底指什么

大纲合规说明第 5 条写的是：

> 「项目中涉及的所有操作均在本地计算机上进行，不包含任何个人数据或敏感信息。」

字面读有歧义。如果它指的是「**数据处理也不得离开本地**」，那么调用百炼 API
本身就与之冲突——**和有没有虚拟机无关**，虚拟机改变不了这一点。

**但大纲自己已经排除了这种读法。** W3 任务 4 明确要求：

> 「开发大模型调用接口，支持开源多模态模型的本地部署**与 API 调用**」

大纲既要求 API 调用，第 5 条就不可能是在禁止数据出本机——否则两处自相矛盾。
因此第 5 条的合理解释是：**被操作的那台电脑在本地**（而不是去控制一台远程
机器或云端桌面），以及**测试环境里不含个人数据**。

这两条我们都满足：客机跑在你自己的机器上；客机内只有为本项目新建的测试
账号与预置测试文件。

### 报告里应当怎么写

不要笼统写「所有操作均在本地进行」——那会把上面的歧义带进报告。准确的表述是：

> GUI 交互在本机的隔离虚拟机内执行，使用预置的合成测试数据；
> 每步截图会发送至所配置的云端多模态模型 API 用于推理；
> 评测环境中不包含任何个人或敏感信息。

> GUI interactions are executed in an isolated local virtual machine using
> synthetic test data; screenshots are transmitted to the configured cloud
> model API for inference, and no personal or sensitive information is
> present in the evaluation environment.

把「哪些东西在本地」「哪些东西出本机」「出本机的东西里有什么」三件事分开写，
事实关系就清楚了，也经得起追问。

## 核对方法

模型与数据集的许可证字段可从 HuggingFace API 直接读，不必依赖记忆：

```bash
curl -s https://huggingface.co/api/models/Qwen/Qwen2.5-VL-3B-Instruct \
  | python -c "import sys,json; d=json.load(sys.stdin)['cardData']; print(d.get('license'), d.get('license_name'))"
```

注意 `license` 为 `None` 而 `license_name` 有值时（如 `qwen-research`），
说明它用的是**自定义许可证**，必须去模型卡片读全文，不能按 SPDX 标准
许可证理解。本表里 Qwen2.5-VL-3B 就是这种情况。
