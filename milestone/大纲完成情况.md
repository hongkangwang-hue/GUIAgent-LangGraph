## 技术栈对照

| 大纲要求 | 实际使用 | 说明 |
|---|---|---|
| Python 3.10+ | ✅ 3.10.20 | |
| PyTorch 2.2+ | ✅ | |
| 本地 GPU 8GB+ 或 Colab | ✅ | 本机 RTX 5060 8GB；训练曾用 AutoDL 4090 |
| Git + GitHub | ✅ | 两个公开仓库 |
| 截图：PyAutoGUI、mss | ⚠ **增加 dxcam** | mss 实测 37ms，dxcam 0.18ms。M1 要求单帧 <15ms，**只有 dxcam 达标**，mss 保留为跨平台回退 |
| UI 识别：OpenCV、PaddleOCR、EasyOCR | ✅ 三个都用 | 有双引擎对照实验（`docs/m1-ocr-双引擎对照实验小结.md`） |

| **跨平台 Windows/macOS/Linux** | ⚠ **只验证 Windows** | 代码有平台分支，但 macOS/Linux **一次没跑过**，不能声称支持 |
| PyQt5 | ⬜ **未使用** | 大纲列在 W2 工具来源里。本项目的界面是 Rich 终端面板，没有 GUI 窗口需求 |
| 多模态模型：Qwen-VL-Chat、GLM-4V-9B、Llama 3.2 Vision 11B | ⚠ **换代 + 部分未跑** | 实际用 **Qwen2.5-VL-3B**（微调）与 **qwen3-vl-8b**（API）。Qwen-VL-Chat 是初代，无原生 grounding 能力；GLM-4V 与 Llama 11B 通道已配置，**未跑评测** |
| Agent 框架：LangChain、LlamaIndex | 🟡 | LangChain 用于模型层；**编排层现用 LangGraph**（LangChain 官方 Agent 编排层），未验证；LlamaIndex 未用（强项是检索，本项目无 RAG 需求） |
